# kana64

64進数を**カタカナだけ**で書くための表記法と、変換ツールです。

```
12345  →  エアリ        （kana64）
6820735 →  ダイコン
```

IDや短い数値を、電話や口頭で伝えやすい文字列にすることを狙っています。

## 特徴

- **1文字＝6ビット＝1拍。** カタカナ1文字が64進数の1桁で、声に出すと1文字1拍です。
- **並び順がそのまま値になる。** アルファベットをUnicodeのコードポイント順に並べているので、同じ桁数どうしなら文字列ソートと数値ソートが一致します。
- **入力に寛容。** 半角カナ、ひらがな、結合濁点、区切り文字（空白・`_`・`-`・`・`）を受け付け、「口→ロ」「力→カ」のような見た目の似た漢字も補正します。
- **使えない文字は理由つきで知らせる。** パ行や小さいカナを入力すると、理由を添えたエラーを返します。
- **依存なし。** TypeScript（Node 22以降）と単一のHTMLだけで動きます。桁数の上限はなく、内部はBigIntです。

## 2つの版

| 版 | 文字集合 | 備考 |
| --- | --- | --- |
| `kana64` | 清音46＋濁音18（ガ・ザ・ダ・バ行） | 基準の版。カタカナだけ |
| `kana64n` | 数字10＋清音46＋濁音8（ガギグゲゴザジズ） | n = numeric。数字が混ざる |

`kana64` のアルファベット（先頭から値0〜63）:

```
アイウエオカガキギクグケゲコゴサザシジスズセゼソゾタダチツテデトドナニヌネノハバヒビフブヘベホボマミムメモヤユヨラリルレロワヲン
```

**2つの版に互換性はありません。** 同じ文字列でも版によって値が変わります（「ア」は `kana64` で0、`kana64n` で10）。

### 使わない文字

| 文字 | 理由 |
| --- | --- |
| ヰ・ヱ | IMEで入力しにくく、読めない人もいる |
| パ行 | バ行と見分けにくい |
| ヂ・ヅ | ジ・ズと発音が同じ（入力時はジ・ズとして受け付ける） |
| 小さいカナ | 通常のカナと紛らわしい |
| 長音「ー」 | 漢字の「一」やダッシュと紛らわしい |

## 使い方

### ブラウザ

`index.html` をブラウザで開くだけです。ページ内で `kana64` と `kana64n` を切り替えられます（URLの `#kana64` / `#kana64n` でも指定可）。

### TypeScript

```ts
import { toKana, fromKana, toAscii, kanaToAscii, group } from "./kana64.ts";

toKana(12345n);          // "エアリ"
fromKana("ダイコン");     // 6820735n
fromKana("だいこん");     // 6820735n（ひらがなも可）

toKana(5n, 4);           // "アアアカ"（minLength で先頭をゼロ埋め）
toAscii(12345n);         // "30u"
kanaToAscii("エアリ");    // "30u"
group(toKana(987654321n)); // "ルヨハニ・ミ"
```

| 関数 | 内容 |
| --- | --- |
| `toKana(n, minLength?)` / `fromKana(s)` | 数値 ⇔ カナ表記 |
| `toAscii(n, minLength?)` / `fromAscii(s)` | 数値 ⇔ ASCII表記 |
| `kanaToAscii(s)` / `asciiToKana(s)` | 表記どうしの変換（1文字ずつの置換） |
| `normalize(s)` | 入力の正規化 |
| `group(s, size?, sep?)` | 表示用の区切り |

`kana64n.ts` も同じ関数を提供します。負の数には対応していません。

### 動作確認

```
node --experimental-strip-types kana64.ts
node --experimental-strip-types kana64n.ts
```

ソート順（2桁の全4096通り）と往復変換（ランダム10000件）を検証します。

## 内部ASCII表記

カナはUTF-8で1文字3バイトになるため、保存や通信にはASCII表記を使う想定です。表示・入力はカナ、内部はASCIIです。

```
0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ_abcdefghijklmnopqrstuvwxyz~
```

ASCIIの並びもコード順と値の順が一致し、URLセーフです。ただし**標準のbase64やbase64urlとは文字の割り当てが違う**ので、既存のbase64ライブラリではデコードできません。

## 注意点

- **表記が一意ではありません。** 先頭に「ア」（値0の文字）を足しても値は変わらないため、`イア` と `アイア` は同じ値です。IDにするなら「先頭の0なし」か「固定桁数」のどちらかに決めてください。
- **意図しない単語ができることがあります。** 普通の単語のように読める文字列が多くなるため、好ましくない言葉が偶然できる可能性があります。
- **見た目の紛らわしさは残ります。** ヘ／へ、シ／ツ、ソ／ン、ロ／口など。入力側は正規化で吸収しますが、読み取りの間違いは防げません。
- チェック用の文字や、任意のバイト列のエンコードは未対応です。
